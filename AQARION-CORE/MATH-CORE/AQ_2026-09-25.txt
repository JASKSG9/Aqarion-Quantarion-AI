Proof — Finite block graph indeg≤1 outdeg≥1 ⇒ permutation

Let k=|X/E|. Assume reflection T^{-1}(E)⊆E.

Lemma: For each target block B meeting im T, T^{-1}(B) contained in single source block. Proof: if x,y∈T^{-1}(B) then E(Tx,Ty) ⇒ E(x,y).

Thus each target block has at most one predecessor: indeg(B)≤1. Formal: if B receives from A,C via T(x)=y∈B, T(z)=y'∈B, then E(Tx,Tz) holds (if same y) or via E(Tx,Ty) argument, in general: choose representatives with same image class? Better: if Tx and Tz lie in same target block B, then E(Tx,Tz) ⇒ E(x,z) ⇒ same source block. So indeg≤1.

Every source block A has at least one outgoing: pick x∈A, then edge to [T(x)].

Let R_T = set of block transitions. Then |R_T| ≥ k (outdeg≥1) and ≤k (indeg≤1). Hence |R_T|=k and indeg=outdeg=1 everywhere ⇒ R_T is permutation.

Therefore E forward invariant: xEy ⇒ same source block ⇒ same target block ⇒ T(x) E T(y). So E ⊆ T^{-1}(E). Combined with hypothesis gives equality.
