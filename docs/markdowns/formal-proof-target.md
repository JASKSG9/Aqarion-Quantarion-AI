The cleanest next theorem to formalize is the nilpotence identity.
THEOREM D_SQUARED_ZERO

Given:

  P² = P
  Q = I - P
  D = Q K P

Then:

  D² = 0.
Proof:
D²
= (QKP)(QKP)
= QK(PQ)KP
Since
PQ
= P(I-P)
= P-P²
= P-P
= 0,
therefore
D² = QK(0)KP = 0.
A second useful theorem:
D P = D
because
DP
= QKPP
= QKP
= D.
And:
P D
= P Q K P
= 0.
These are excellent C4 targets because they require no finite enumeration and no probabilistic reasoning.
