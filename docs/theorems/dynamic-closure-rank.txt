THEOREM — DYNAMIC-CLOSURE RANK SUBMODULARITY

Let X be finite and T : X → X.

For a partition P of X, let E(P) be the set of unordered pairs
contained in a common block of P.

Define

O_T(E) = ⋃_{j≥0} T^j(E),

where

T^j({x,y}) = {T^j(x),T^j(y)}.

Let C_T(P) be the least T-invariant equivalence relation
containing P.

Define

B∞(P) = |C_T(P)|

and

ρ∞(P) = |X| - B∞(P).

Claim:

ρ∞ is submodular on the partition lattice.
Equivalently, B∞ is supermodular.

Proof.

Lemma 1.
C_T(P) is the connected-component partition of

G_P = (X, O_T(E(P))).

Proof.
The graph contains E(P), hence its connected-component equivalence
contains P.

It is T-invariant because applying T to an orbit edge produces another
orbit edge.

Therefore its component equivalence is a T-invariant equivalence
containing P.

Conversely, every T-invariant equivalence containing P contains every
T^j-image of every P-edge, hence contains O_T(E(P)).
Therefore it contains every connected component of G_P.

Thus the two equivalence relations coincide.

Hence

ρ∞(P)
=
r_gr(O_T(E(P))).

Lemma 2.
For all P,Q,

O_T(E(P ∧ Q))
⊆
O_T(E(P)) ∩ O_T(E(Q)).

Proof.
E(P ∧ Q) ⊆ E(P) ∩ E(Q).
The orbit operator is monotone, so

O_T(E(P ∧ Q))
⊆
O_T(E(P) ∩ E(Q))
⊆
O_T(E(P)) ∩ O_T(E(Q)).

Lemma 3.
The graphs

O_T(E(P ∨ Q))

and

O_T(E(P)) ∪ O_T(E(Q))

have the same connected components.

Proof.
Because

E(P) ∪ E(Q) ⊆ E(P ∨ Q),

their orbit union is contained in
O_T(E(P ∨ Q)).

Thus every component of the orbit union is contained in a component
of the join orbit graph.

Conversely, every edge of E(P ∨ Q) lies on a finite alternating path
whose edges belong to E(P) ∪ E(Q), because P ∨ Q is the equivalence
relation generated by P- and Q-equivalence.

Applying T^j to that path gives a path whose edges lie in

O_T(E(P)) ∪ O_T(E(Q)).

Therefore every edge of O_T(E(P ∨ Q)) has endpoints connected in the
orbit union graph.

Thus the two graphs have identical connected-component partitions.

Consequently,

r_gr(O_T(E(P ∨ Q)))
=
r_gr(O_T(E(P)) ∪ O_T(E(Q))).

Lemma 4.
Graphic rank is submodular:

r_gr(A)+r_gr(B)
≥
r_gr(A∩B)+r_gr(A∪B).

Therefore,

ρ∞(P)+ρ∞(Q)

=
r_gr(O_T(E(P)))
+
r_gr(O_T(E(Q)))

≥
r_gr(
  O_T(E(P)) ∩ O_T(E(Q))
)
+
r_gr(
  O_T(E(P)) ∪ O_T(E(Q))
)

≥
r_gr(
  O_T(E(P ∧ Q))
)
+
r_gr(
  O_T(E(P ∨ Q))
)

=
ρ∞(P ∧ Q)+ρ∞(P ∨ Q).

Therefore ρ∞ is submodular.

Since

B∞ = |X| - ρ∞,

B∞ is supermodular.

QED.
