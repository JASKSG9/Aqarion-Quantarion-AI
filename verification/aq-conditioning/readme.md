AQARION-CONDITIONING
Exact Rank vs Numerical Conditioning Verification
AQARION-CONDITION8NG is a nested AQARION verification package for comparing exact finite linear-algebra classification with floating-point singular-value diagnostics. It lives at:
verification/aq-conditioning/
The outer folder name intentionally uses a hyphen because it is a repository path. The inner Python package uses an underscore because Python module names cannot contain hyphens:
verification/aq-conditioning/aq_conditioning/
This package is scoped to finite, declared matrix fixtures. It does not claim a proof of the Riemann Hypothesis, a Connes adèle-class-space implementation, a spectral realization of zeta zeros, C4 clearance, publication readiness, or promotion.

python -m aq-conditioning.replay
Use the working directory and then the underscored package:
python -m aq_conditioning.replay
